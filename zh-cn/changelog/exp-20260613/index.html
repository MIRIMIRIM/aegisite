exp-20260613

exp分支的第一个正式版本，本分支目前仅保证windows可用。

标签时版本号：r9730。下载见 Release。

主要变更

  • 升级 C++ 与主要依赖，部分依赖改为动态加载
  • 支持 LayoutRes X/Y
  • 重写并拆分字体收集器（仅 Windows）
  • 支持 HDR / Dolby Vision 预览（需要 libplacebo 和 lsmasnative）
  • 支持生成关键帧（需要 scenechange_native 和 lsmasnative）
  • 支持视频画面平移 / pan 功能（拆分视频暂不支持）
  • 音频频谱改用 pffft（替代 FFTW3）
  • 音频频谱增加多种渲染样式，修复了一些抵消不可见的问题
  • Lua 增加 luasocket 与调试相关能力
  • 引入 libmatroska 解析 MKV，并使用附件字体正确渲染内嵌字幕
  • 支持副字幕 / secondary subtitle 预览（拆分视频暂不支持）
  • 性能优化、修 bug，以及新的 bug

主要依赖 / 构建信息

  • C++ 20
  • wxWidgets: 3.3.1
  • libass: 0.17.4
  • Boost: 1.90.0
  • pffft: 1.1.0
  • Lua: LuaJIT 2.1.0-beta3、luabins、luasocket v3.1.0
  • libmatroska: 1.7.1

动态加载依赖

视频 / 音频源滤镜

  • avisynth: AviSynthPlus v3.7.5
  • ffms2: 5.0
  • lsmasnative: LsmasSharp/202606，基于 L-SMASH-Works/20260326
  • ragbag-subtitle-ffmpeg：RagbagSubtitle v0.1.0

其它滤镜

  • libplacebo: v7.360.1-20260318
  • scenechange_native: SceneChangeSharp v0.0.2

字幕滤镜

  • assrender_textsub / assrender_ob_textsub: assrender/0.38.4
  • pf-xy-vsfilter_textsub: pinterf/xy-VSFilter 3.2.0.810
  • vsfiltermod_textsub: VSFilterMod r5.2.7-beta-2
  • vsfilter_textsub: xy-VSFilter r3
