r9990 beta 20260911

Beta 通道 GHA 快照（无 GitHub Release）。r9990，相对 r9942 beta-20260813 的变更。

请从 Actions 下载 aegisub-win-x64-portable.zip。

编辑与界面

  • 字幕栏：新增连续行可持久折叠功能，可以持久化到 ExtraData _aegi_folddata；完整组复制 / 粘贴会带上折叠，撤销重做可用

    • 菜单在字幕栏右键和「字幕」里的 Fold Groups
    • 新增命令：grid/fold/create、grid/fold/toggle、grid/fold/expand、grid/fold/collapse、grid/fold/clear、grid/fold/expand/all、grid/fold/collapse/all、grid/fold/clear/all

  • 取色功能：

    • 编辑框颜色按钮：增加双击激活取色器放大镜，可以从当前视频帧取色，Esc / 右键取消
      • 双击取色时的采样路径来自 raw 帧，取区域中值色，原取色算法不变
    • 编辑框（wxSTC）：颜色标签的文本底部可以展示相应颜色（Subtitle/Highlight/Color Swatches，默认开启），点击色块打开对应槽位的取色器
    • 新增命令：edit/color/primary/pick/video、edit/color/secondary/pick/video、edit/color/outline/pick/video、edit/color/shadow/pick/video

  • 编辑框（wxSTC）：新增标签块的快速移动，Alt+Left / Alt+Right 按块移动光标所在的 {...} override 或 \N / \n / \h

  • 编辑框：修复清空边距字段是变成最小值，现在写 0；层 / 边距 SpinCtrl 内的 Ctrl+C/X/V 作用于控件文本，不再误触发复制 / 剪切 / 粘贴字幕行

  • 时间轴平移：拒绝空、部分解析、越界和无法取反的帧偏移，同步自 samgum/Aegisub@7c875d1

  • 性能优化：窗口缩放只重绘受影响的窗口和字幕栏区域

可视化排版

  • 缩放工具：可把 X 或 Y 归一到 100% 并保持比例，新增命令：video/tool/scale/normalize/x、video/tool/scale/normalize/y

  • 拖拽工具：\move / \pos 切换按钮在使用后正确更新选中态与图标

  • 设置：可视化工具增加独立设置页，微移步长可改为浮点

  • 测量工具：新增命令 video/tool/measure/segment、、video/tool/measure/guide/delete

  • 测量工具：新增 Perspective 子模式功能，在视频上画目标四边形（关闭 Fit Text 时内部虚线框可以作为预览），Apply 后按渲染器语义写入透视相关标签

    • 选项在新的 Preferences > Visual Tools：Fit Text、Fax + Frz Only、小数位数
    • 新增命令：video/tool/measure/perspective、video/tool/measure/perspective/apply（默认 Enter）

  • 运动追踪：新增运动追踪对话框与叠加层（video/tool/motion_track）：在视频上框选 ROI，Analyze 后 Apply 写入轨迹，Apply 前可以在视频上预览路径

    • 目前只支持平移（Translation）、相似变换（Similarity，旋转 + 均匀缩放）
    • Apply：Compact（默认，平移用 \move；Similarity Compact 另用 \t 写 \frz / \fscx / \fscy）或 Exact（逐帧）
    • 其他功能：轨迹平滑 / 稳定、检测到淡入淡出时写 \fad、Similarity Exact 下按缩放改 \bord / \shad / \blur
    • 新增命令：video/tool/motion_track

视频 / 对帧

  • 暂停时预取后续帧进缓存；播放等到第一帧送达再开始，避免音画抢跑
  • 中键 seek：按下未拖动时保持音频连续；播放结束仍按住中键时，松开后会按原意图继续
  • 跳过未变化的画布 resize
  • 对帧工具：新增扫描时显示进度对话框
  • 对帧工具：新增选项可以把 fade 时间四舍五入到 10 ms（默认关闭）
  • 对帧工具：视频被换掉后拒绝继续扫描

音频

  • XAudio2：用高分辨率时钟推进播放位置；重启播放时交替缓冲组
  • 频谱缓存老化与 provider 读取解耦，减少读取抖动带来的显示空洞
  • lsmasnative：短暂短读不再把静音写进缓存

副字幕 / ASS

  • 副字幕：修复 SRT 样式目录尚未创建时弹出 watcher 错误
  • 副字幕：优化分离模式下的边框显示
  • ASS：裸 Event 前缀防止迭代器越界，同步自 TypesettingTools/Aegisub@6cd9e23
  • ASS：私有和嵌入 section 去掉嵌入 NUL，同步自 TypesettingTools/Aegisub@b5bf239、TypesettingTools/Aegisub@0a3073d
  • VFR：未加载 fps 时保护帧到时间转换，同步自 TypesettingTools/Aegisub@774ebb6

自动化 / Lua

修改的脚本，以下需要覆盖原脚本，覆盖前做好原脚本备份：

  • automation/include/aegisub/lfs.moon：lfs.dir 打不开目录时立即报错（对齐 vanilla lfs），不再返回空迭代器；error 参数顺序修正；同步自 TypesettingTools/Aegisub@00a0537、TypesettingTools/Aegisub@0007818、TypesettingTools/Aegisub@38e57a3
  • automation/include/aegisub/re.moon：search / match / replace 的 native 异常改为 Lua error，不再穿过 LuaJIT 栈；compile 失败时抛出真正的错误字符串；同步自 TypesettingTools/Aegisub@38e57a3
  • automation/include/aegisub/ffi.moon：按 ffi.typeof 判断是否 free C 字符串，避免类型比较错误；同步自 TypesettingTools/Aegisub@38e57a3、TypesettingTools/Aegisub@4f267dc

配套宿主：

  • aegisub.clipboard.get：返回可释放的 char*，避免 FFI 字符串泄漏
  • Lua 替换 subs[n] 时保留 Dialogue Id，折叠与选区恢复不会丢身份

其他功能

  • 新增 Discord Rich Presence，设置在 Preferences > General > Discord，默认关闭；连接后可以在 Discord 显示字幕文件名和会话时长

构建 / 打包 / 运行时

  • Release 默认开启 LTO（CMAKE_INTERPROCEDURAL_OPTIMIZATION_RELEASE，工具链不支持则需关掉）
