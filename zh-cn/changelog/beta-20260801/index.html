beta 20260801

Beta 通道 GHA 快照（无 GitHub Release）。相对带标签发布 exp-20260613 的变更。

请从 Actions 下载 aegisub-win-x64-portable.zip。

编辑与界面

  • 样式管理器：清空边距 / 描边 / 阴影时恢复为 0 而非默认样式值
  • 编辑框：优化命令条（command bar）的稳定性
  • 编辑框（wxSTC）：括号、大括号高亮匹配
  • 编辑框（wxSTC）：在光标处分割时去掉 UTF-8 空白
  • 编辑框（wxSTC）：选择文本拖拽时实时预览结果
  • 编辑框（wxSTC）：显示标记，在menu的view和设置的interface中开启和控制，对于错误的字符鼠标停置可提供相关信息
  • 编辑框：边距可调步进，默认 1；值范围与 VSFilter 边距范围对齐，支持负边距
  • 字幕网格：支持负边距显示
  • 字幕网格：选择锚点导航用于固定、跳转（grid/selection/back、grid/selection/forward）
  • 命令 / 热键：增加鼠标侧键 1/2 支持，默认绑定 grid/selection/back 和 forward
  • 「重新加载外部更改」改为运行时选项（无需重启）

字体

主要涉及样式编辑器、编辑栏的字体选择、字体收集器、字体名称规范化（新增功能）。

  • 字体选择增加偏好本地化名称选项（General/ASS Font Names/Prefer localized font family names），默认开启，关闭的话会显示英文family name而不是本地化后的名称
  • 关闭「偏好本地化名称」时始终使用自定义对话框选字体，会先建立 Windows 字体缓存
  • 字体收集器：优化收集逻辑

查找 / 替换

  • 修复区分大小写与偶发匹配错误
  • 增加按样式筛选
  • 全部查找、全部替换会弹出结果对话框，双击可以跳转指定行

副字幕

  • 副字幕：可从视频加载（默认不自动加载）；会话内可切换已加载源
  • 副字幕：支持分离视频，生命周期与状态加固
  • 副字幕：支持 VobSub IDX/SUB
  • 副字幕：downscale 使用更高质量的算法

可视化排版

  • 持久测量参考线；测量工具箭头、可选标签框、fax / fay / 角度读数
  • 键盘微移、矢量裁剪子模式与热键
  • 双击定位时保留多选
  • 共享拖拽管线优化
  • Skia 可视化工具：叠加层缓存 / 生命周期；需要时默认仍对齐旧版拖拽

视频 / 场景切换检测

  • libplacebo：修复特定环境下的花屏，提升稳定性
  • ffms2：SIMD BGRA 变换
  • 视频详情：使用精准的 FPS 如 24000/1001 而不是 23.976 之类的数字
  • 视频框：支持输入帧号跳转
  • 对帧工具：优化色彩匹配算法
  • 场景切换检测：新增 scxvid 支持，默认使用 wwxd
  • 命令 / 热键：修复与上游原始功能的不一致，video/reset_pan → video/pan_reset
  • 优化多轨道选择框，避免过长无法选择

音频

  • 新增 Skia 音频显示管线，默认不启用，需要手动启用与重启应用生效
  • 新增游标拖拽死区，可配置，默认 5px
  • 设置中可自定义 audio/play/section/* 范围，默认 500ms

自动化

  • 增加依赖 skia 的 shape api，用于替代依赖 qt 的 a3shape

CLI

  • 把 fontcollecor cli 合并到本体，通过 Aegisub fontcollector 调用
  • 用 CLI11 处理命令解析

打包 / 运行时

  • 更新 assdraw3 为 x64 hidpi 版本
  • libass 动态加载
  • 更新 lsmasnative、scenechange_*、ragbag_subtitle 等打包依赖
  • Windows 目标：_WIN32_WINNT / WINVER 0x0A00（Windows 10 1703+）
