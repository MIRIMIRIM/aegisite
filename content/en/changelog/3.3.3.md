[wangqr/Aegisub](https://github.com/wangqr/Aegisub/releases/tag/v3.3.3) release, based on **[r8942](/changelog/r8942/)**. Last tagged release on that fork before later AmusementClub work.

### Changes after v3.3.2

- Pass storage size to libass to fix rendering (@TheOneric)
  - Changes how subtitles render in some cases with libass; matches ffmpeg ≥ 5.0.1 and VLC nightly
- Added CoreAudio player for macOS (multi-channel) (@IbarakiKasen)
- Choose between wxStyledTextCtrl and wxTextCtrl for the subtitle edit box
  - wxSTC: syntax highlighting
  - wxTextCtrl: native control (often better IME / RTL); Shift+right-click for native context menu
- Support for negative margin (@petzku)
- Fix timestamp issue when loading subtitle from MKS
- Fix support for embedded fonts in ASS (@Kienyew)
- Fix build issues with boost ≥ 1.76, M1 Mac, etc.
