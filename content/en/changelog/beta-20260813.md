**Beta channel** GHA snapshot (no GitHub Release). r9942; changes since [r9925 beta-20260807](/changelog/beta-20260807/).

Download `aegisub-win-x64-portable.zip` from [Actions](https://github.com/AmusementClub/Aegisub/actions/runs/94341021860).

### Editing and UI

- Subtitle grid: optimize sorting performance
- Subtitle grid: new Skia CPU drawing backend; on Windows, text rendering uses DirectWrite, which improves rendering efficiency and text quality compared to the wx + GDI combination. Option under `Interface/Grid`, takes effect after restart, off by default
- Subtitle grid: fix the change in Ctrl + drag behavior
- Autosave: now asynchronous, reduces stuttering to some extent

### Fonts

- Font selection: removed the preview box; now previews live on the video

### Video / Scene change detection

- Visual tools: fix video stuttering when moving quickly during playback
- Visual tools: fix performance issues such as stuttering when dragging multiple subtitle lines at once
- Fix frame number not following the video when the cursor is in the frame number text box
- Align tool: new fade support, auto-generates `\fad` tags, prefers opaque and white text regions as anchors

### Audio

- Optimize rendering performance with very many marker lines and selections
- Skia display: fix missing text and display gaps caused by prefetch races
- Skia display: UI and operation logic now more consistent with the traditional audio display
- XAudio2: strengthen playback lifecycle
