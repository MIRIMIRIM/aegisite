[wangqr/Aegisub](https://github.com/wangqr/Aegisub/releases/tag/v3.3.1) release.

### Changes after v3.3.0

- Added XAudio2 audio player for Windows (multi-channel output)
- Fix build issues on macOS
- Added support for AviSynth+ on Linux (CMake only)
- Fix video rendering performance issue with visual tools
- Merge changes from upstream

### Notes

- If `vcruntime140_1.dll` is missing, install the [VC++ redistributable](https://support.microsoft.com/en-gb/help/2977003/the-latest-supported-visual-c-downloads) or check Windows Update.
- macOS build was experimental; check open/closed issues before relying on it.
