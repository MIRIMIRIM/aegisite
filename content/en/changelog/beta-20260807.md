**Beta channel** GHA snapshot (no GitHub Release). r9925; changes since [r9903 beta-20260804](/changelog/beta-20260804/).

Download `aegisub-win-x64-portable.zip` from [Actions run](https://github.com/AmusementClub/Aegisub/actions/runs/31174221631).

### Editing and UI

- Edit box (wxSTC): double-click tag selection now also covers `\N`, `\n`, and `\h`
- Edit box (wxSTC): experimental `Subtitle/Edit Box/Use DirectWrite` — can fix some performance and rendering issues; needs testing on Windows 10, RDP, and similar setups
- Edit box (wxSTC): performance work (avoid full rebuilds, etc.)
- Reload external changes: fix change prompt still appearing on close
- Markers: fix incorrect menu state

### Fonts

Style editor and edit-box font selection.

- Style editor / font picker: fix keyboard selection picking the wrong item
- Style editor / font picker: fix cursor display when the dropdown auto-opens (Windows API limits mean the correct cursor only shows after the list closes)
- Style editor / font picker: fix the dropdown re-opening repeatedly when auto-expand is on
- Font picker: fix showing the font from the previous tag block
- Font picker: with “prefer localized” on, also use the custom dialog instead of the native Windows dialog

### Find / Replace

- Results dialog: rename the Line column to Line number (avoids bad Chinese translations)

### Secondary subtitle

- Secondary subtitle: more stable SRT style use and rendering

### Visual tools

- Measurement guides: style pass — smaller endpoints to reduce occlusion, smaller arrows, thinner lines
- Performance improvements

### Plugins (experimental)

- Enable the bridge so more APIs can be exposed as plugins. Currently supports .NET CoreCLR JIT and NativeAOT; the latter uses C ABI and should work with any language that can interop via C ABI

### Build / packaging / runtime

- Windows version-string script: better PowerShell 5.1 compatibility
- plugin: add dependency-control v0.1.0 (NativeAOT)
