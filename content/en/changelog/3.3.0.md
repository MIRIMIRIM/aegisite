[wangqr/Aegisub](https://github.com/wangqr/Aegisub/releases/tag/v3.3.0) release, based on upstream trunk **[r8942](/changelog/r8942/)**.

For changes from v3.2.2 to r8942, see [plorkyeran trunk builds](http://plorkyeran.com/aegisub/) or [r8942](/changelog/r8942/).

### Changes after r8942

- Added the "align to hardsub in video" function (thanks to @cqjjjzr)
- Allow user change color for visual typesetting tool (thanks to @CoffeeFlux)
- Bug fixes about HiDPI display issues
- Bug fixes about timing calculation for video frame and audio FFT
- Updated default configs (thanks to @CoffeeFlux)
- Other fixes for building issues with updated dependencies
- Experimental CMake build

### Notes

- **2019-09-10:** Rebuilt due to [wangqr/Aegisub#16](https://github.com/wangqr/Aegisub/issues/16)
- **2019-10-02:** Added win32 build. Keep in mind that if you use 32-bit builds, you will NOT be able to use more than 4GiB memory, and performance will suffer due to the additional WoW64 emulation layer, and lack of SIMD instructions. The performance impact is especially noticeable in fftw (for audio spectrum) and AviSynth. Unless you are using some legacy tools that either no longer maintained, or for some reason cannot use 64-bit, or you are actually using a 32-bit CPU, please use the 64-bit version. SSE2 is still REQUIRED to run the 32-bit version
- **2019-11-11:** Rebuilt win32 build due to missing uchardet.dll. Moved old builds to [https://ftp.wangqr.tk/aegisub/backup/](https://ftp.wangqr.tk/aegisub/backup/) (They are not for daily use, only for audit purpose).
