The first official release of the `exp` branch; currently, this branch is guaranteed to work only on Windows.

Revision at tag: **r9730**. Assets: [release](https://github.com/AmusementClub/Aegisub/releases/tag/exp-20260613).

### Major changes

- Upgrade C++ and major dependencies, and split some dependencies into dynamic loading
- Support LayoutRes X/Y
- Rewrite and split font collector (Windows)
- Support preview HDR and Dolby Vision, provided by libplacebo and lsmasnative
- Support generate keyframe, provided by scenechange_native and lsmasnative
- Support pan in attached video
- Using pffft instead of FFTW3 for audio spectrum mode
- Audio spectrum mode add more rendering styles
- Lua add luasocket and a debugging feature
- Introduce libmatroska for mkv info parsing, and use the fonts in the attachment to render embedded subtitle correctly
- Add secondary subtitle in attached video
- Performance optimizations, bug fixes, and new bugs
