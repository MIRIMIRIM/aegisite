**Beta channel** GHA snapshot (no GitHub Release). r9903; changes since [beta 20260801](/changelog/beta-20260801/).

Download `aegisub-win-x64-portable.zip` from [Actions run](https://github.com/AmusementClub/Aegisub/actions/runs/30934967206).

### Editing and UI

- Double-click on an override tag selects the whole `\tag(args)` span

### Fonts

Style editor and edit-box font selection.

- Font preview follows line style and the tag block at the caret
- Optional “expand font list while typing” (arrow keys + Enter); off by default

### Find / Replace

- Results dialog: “Replaced line” column
- Results stay in sync when you edit from the dialog (edited rows update and grey out)
- Esc closes the dialog and restores focus to Find / Replace
- Highlight keywords in original and replaced lines

### Automation

- `aegisub.scroll_audio_to(time_ms)` centers the audio display on a time

### Packaging / runtime

- Version metadata: `BUILD_GIT_BUILD_TIME` / `BUILD_GIT_BUILD_TIME_UTC` (timezone via `BUILD_TIME_OFFSET`, default +8)
