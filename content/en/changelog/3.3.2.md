[wangqr/Aegisub](https://github.com/wangqr/Aegisub/releases/tag/v3.3.2) bugfix release after 3.3.1 (no new features).

### Changes after v3.3.1

- Show a notice when the 32-bit memory limit is reached instead of crashing
- Fix OpenGL color depth issue with some GPU drivers
- Use XAudio2redist for better Windows 7 support
- Fix multiple issues with the 3.3.1 macOS build
- Fix eyedropper not working
- Fix alt-drag behavior in the audio window
- Fix saving audio clip with float samples
- Delete temporary files on close on Windows
