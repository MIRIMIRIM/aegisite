**Beta channel** GHA snapshot (no GitHub Release). r9990; changes since [r9942 beta-20260813](/changelog/beta-20260813/).

Download `aegisub-win-x64-portable.zip` from [Actions](https://github.com/AmusementClub/Aegisub/actions/runs/34564602751).

### Editing and UI

- Subtitle grid: new persistent folding for contiguous lines, stored in ExtraData `_aegi_folddata`; copy / paste of a complete group keeps the fold; undo / redo work
  - Menu: grid context menu and Subtitle → **Fold Groups**
  - New commands: `grid/fold/create`, `grid/fold/toggle`, `grid/fold/expand`, `grid/fold/collapse`, `grid/fold/clear`, `grid/fold/expand/all`, `grid/fold/collapse/all`, `grid/fold/clear/all`

- Color picking:
  - Edit-box color buttons: double-click arms the eyedropper magnifier and picks from the current video frame; `Esc` / right-click cancels
    - Double-click sampling reads the raw frame and takes the region median; the original picker algorithm is unchanged
  - Edit box (wxSTC): color tag text can show the corresponding color underneath (`Subtitle/Highlight/Color Swatches`, on by default); click the swatch to open that slot's picker
  - New commands: `edit/color/primary/pick/video`, `edit/color/secondary/pick/video`, `edit/color/outline/pick/video`, `edit/color/shadow/pick/video`

- Edit box (wxSTC): new quick move for tag blocks; `Alt+Left` / `Alt+Right` walks the `{...}` override or `\N` / `\n` / `\h` under the caret
- Edit box: fix clearing a margin field writing the minimum value; it now writes 0. `Ctrl+C/X/V` in the layer / margin SpinCtrls edits the field text instead of cutting / copying / pasting subtitle lines
- Shift Times: reject empty, partial, out-of-range, and non-negatable frame offsets; synced from [samgum/Aegisub@7c875d1](https://github.com/samgum/Aegisub/commit/7c875d19775e392ee1907a91766ce11229de0ccd)
- Performance: window resize redraws only affected windows and grid regions

### Visual typesetting

- Scale tool: normalize X or Y to 100% while keeping the ratio. New commands: `video/tool/scale/normalize/x`, `video/tool/scale/normalize/y`
- Drag tool: the `\move` / `\pos` toggle updates its checked state and icon after use
- Preferences: visual tools get their own page; nudge steps can be floating-point
- Measure tool: new commands `video/tool/measure/segment`, `video/tool/measure/guide/delete`
- Measure tool: new Perspective submode. Draw a target quadrilateral on the video (with `Fit Text` off, the inner dashed box can be used as a preview); **Apply** writes renderer-faithful perspective tags
  - Options on the new `Preferences > Visual Tools` page: `Fit Text`, `Fax + Frz Only`, decimal places
  - New commands: `video/tool/measure/perspective`, `video/tool/measure/perspective/apply` (default `Enter`)

- Motion tracking: new motion-track dialog and overlay (`video/tool/motion_track`): draw an ROI on the video, Analyze, then Apply the trajectory; the path can be previewed on the video before Apply
  - Currently supports Translation and Similarity (rotation + uniform scale)
  - Apply: Compact (default; `\move` for translation; Similarity Compact also writes `\frz` / `\fscx` / `\fscy` via `\t`) or Exact (per frame)
  - Other options: trajectory smoothing / stabilization, write `\fad` when a fade is detected, scale `\bord` / `\shad` / `\blur` with zoom in Similarity Exact
  - New command: `video/tool/motion_track`

### Video / Align to video

- Prefetch upcoming frames into the cache while paused; playback waits for the first delivered frame so audio cannot run ahead
- Middle-click seek: keep audio continuous when the press does not drag; if playback finishes while the button is still held, release continues with the original intent
- Skip unchanged canvas resize work
- Align tool: show a progress dialog while scanning
- Align tool: new option to round fade times to 10 ms (off by default)
- Align tool: refuse to keep scanning if the video was swapped out

### Audio

- XAudio2: advance playback with a high-resolution clock; alternate buffer banks when restarting playback
- Spectrum cache aging is independent of provider reads, reducing display gaps from read jitter
- lsmasnative: do not cache silence from transient short reads

### Secondary subtitle / ASS

- Secondary subtitle: fix watcher error popups when the SRT style catalog directory does not exist yet
- Secondary subtitle: improve the border in detached mode
- ASS: guard bare Event prefixes against iterator overflow; synced from [TypesettingTools/Aegisub@6cd9e23](https://github.com/TypesettingTools/Aegisub/commit/6cd9e23232a43bc087a1c2acfd7425eb142f614d)
- ASS: strip embedded NULs from private and embedded sections; synced from [TypesettingTools/Aegisub@b5bf239](https://github.com/TypesettingTools/Aegisub/commit/b5bf23979e7453f7b1cc8ffeb82b3cc2d2ca75e6), [TypesettingTools/Aegisub@0a3073d](https://github.com/TypesettingTools/Aegisub/commit/0a3073d59f10432eeebea65018b02ef4d0a87fff)
- VFR: guard frame-to-time conversion when fps is not loaded; synced from [TypesettingTools/Aegisub@774ebb6](https://github.com/TypesettingTools/Aegisub/commit/774ebb65386aa0ba6ff37b920054fd9f8f0d4496)

### Automation / Lua

Modified scripts. **These need to overwrite the original scripts; back up the originals first:**

- `automation/include/aegisub/lfs.moon`: `lfs.dir` errors immediately on an unopenable directory (vanilla lfs contract) instead of yielding an empty iterator; `error` argument order fixed; synced from [TypesettingTools/Aegisub@00a0537](https://github.com/TypesettingTools/Aegisub/commit/00a05370a1d23f073a6699690872c2bee82341b7), [TypesettingTools/Aegisub@0007818](https://github.com/TypesettingTools/Aegisub/commit/00078188b51de3a04754bafbbd26a792df3fa965), [TypesettingTools/Aegisub@38e57a3](https://github.com/TypesettingTools/Aegisub/commit/38e57a327e6a7d9e0553d8960e417b8144766383)
- `automation/include/aegisub/re.moon`: native exceptions from `search` / `match` / `replace` become Lua errors instead of unwinding through LuaJIT; `compile` failures raise the actual error string; synced from [TypesettingTools/Aegisub@38e57a3](https://github.com/TypesettingTools/Aegisub/commit/38e57a327e6a7d9e0553d8960e417b8144766383)
- `automation/include/aegisub/ffi.moon`: decide whether to `free` a C string with `ffi.typeof`, avoiding a broken type comparison; synced from [TypesettingTools/Aegisub@38e57a3](https://github.com/TypesettingTools/Aegisub/commit/38e57a327e6a7d9e0553d8960e417b8144766383), [TypesettingTools/Aegisub@4f267dc](https://github.com/TypesettingTools/Aegisub/commit/4f267dc52d9d683b02ed4326442b908341970f5a)

Host-side:

- `aegisub.clipboard.get`: returns a freeable `char*`, avoiding an FFI string leak
- Replacing `subs[n]` keeps the Dialogue `Id`, so folding and selection restoration keep their identity
