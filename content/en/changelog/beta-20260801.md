**Beta channel** GHA snapshot (no GitHub Release). Changes since tagged [exp-20260613](/changelog/exp-20260613/).

Download `aegisub-win-x64-portable.zip` from [Actions run](https://github.com/AmusementClub/Aegisub/actions/runs/30692940546).

### Editing and UI

- Style manager: clearing margin / outline / shadow restores `0` instead of style defaults
- Edit box: more stable command bar
- Edit box (wxSTC): highlight matching parentheses / braces
- Edit box (wxSTC): trim UTF-8 spaces when splitting at cursor
- Edit box (wxSTC): live preview when dragging selected text
- Edit box (wxSTC): display markers (View menu / Interface options); hover explains invalid characters
- Edit box: editable margin step (default 1); range matches VSFilter, including negative margins
- Subtitle grid: show negative margins
- Subtitle grid: selection-anchor navigation (`grid/selection/back`, `grid/selection/forward`)
- Commands / hotkeys: mouse side buttons 1/2 (default bound to selection back/forward)
- “Reload external changes” is a runtime option (no restart)

### Fonts

Style editor, edit-box font picker, font collector, and font-name normalization.

- Prefer localized font family names (General / ASS Font Names; on by default); off shows English family names
- With prefer-localized off, always use the custom font dialog (builds Windows font cache first)
- Font collector: collection logic improvements

### Find / Replace

- Fix match-case and occasional wrong matches
- Filter by style
- Find-all / replace-all open a results dialog; double-click jumps to the line

### Secondary subtitle

- Load from video (autoload off by default); switch loaded sources in-session
- Detached video support; lifecycle/state hardening
- VobSub IDX/SUB support
- Higher-quality downscale

### Visual typesetting

- Persistent measurement guides; measure tool arrows, selectable label, fax/fay/angle readouts
- Keyboard nudge, vector-clip submodes, hotkeys
- Keep multi-selection on double-click positioning
- Shared drag pipeline optimizations
- Skia visual tools: overlay cache/lifecycle; legacy-aligned drag when needed

### Video / scene change

- libplacebo: fix garbage frames in some environments; stability
- ffms2: SIMD BGRA transform
- Video details: exact FPS (e.g. 24000/1001) instead of rounded values
- Video box: jump to frame number
- Align-to-hardsub: better color matching
- Scene change: scxvid support; default backend wwxd
- Commands: `video/reset_pan` → `video/pan_reset`
- Long multi-track chooser scrolls instead of overflowing

### Audio

- Skia audio display pipeline (off by default; enable + restart)
- Marker drag dead zone (configurable, default 5px)
- Preferences for `audio/play/section/*` ranges (default 500ms)

### Automation

- Skia-based shape API (replacing Qt-dependent a3shape)

### CLI

- Font collector CLI merged into the main binary: `Aegisub fontcollector`
- CLI11 for command parsing

### Packaging / runtime

- assdraw3 x64 HiDPI build
- libass loaded dynamically
- Updated packaged lsmasnative, scenechange_*, ragbag_subtitle, etc.
- Windows target: `_WIN32_WINNT` / `WINVER` 0x0A00 (Windows 10 1703+)
