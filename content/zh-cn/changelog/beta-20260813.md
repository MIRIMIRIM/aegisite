**Beta 通道** GHA 快照（无 GitHub Release）。r9942，相对 [r9925 beta-20260807](/zh-cn/changelog/beta-20260807/) 的变更。

请从 [Actions](https://github.com/AmusementClub/Aegisub/actions/runs/31637393003) 下载 `aegisub-win-x64-portable.zip`。

### 编辑与界面

- 字幕栏：优化排序性能
- 字幕栏：新增 Skia CPU 绘制后端，在 Windows 上文字渲染使用 DirectWrite，相比 wx + GDI 的组合提升了渲染效率和文本渲染质量。选项在 `Interface/Grid`，切换重启生效，默认关闭
- 字幕栏：修复 Ctrl 加拖拽行为的变更
- 自动保存：改为异步，一定程度上降低卡顿

### 字体

- 字体选择：删除预览框，改为在视频上实时预览

### 视频 / 场景切换检测

- 可视化排版工具：修复视频播放时快速移动的视频卡顿
- 可视化排版工具：修复多行字幕同时拖动的卡顿等性能问题
- 修复光标在帧号文本框时，帧号不跟随视频变化的问题
- 对帧工具：新增 fade 支持，自动生成 `\fad` 标签，尽量选择不透明和白色文本区域作为锚点

### 音频

- 优化超多标记线、选区时的渲染性能
- Skia 显示管线：修复文字缺失和预取竞争导致的显示缺失
- Skia 显示管线：UI 和操作逻辑更多地与传统音频显示管线保持一致
- XAudio2: 强化播放生命周期
