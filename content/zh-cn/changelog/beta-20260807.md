**Beta 通道** GHA 快照（无 GitHub Release）。r9925，相对 [r9903 beta-20260804](/zh-cn/changelog/beta-20260804/) 的变更。

请从 [Actions](https://github.com/AmusementClub/Aegisub/actions/runs/31174221631) 下载 `aegisub-win-x64-portable.zip`。

### 编辑与界面

- 编辑框（wxSTC）：标签双击全量选择新增对 `\N`、`\n`、`\h` 的支持
- 编辑框（wxSTC）：新增实验性 `Subtitle/Edit Box/Use DirectWrite`，该选项可以解决一些性能问题和渲染问题，但在 Windows 10、RDP 等场景需要测试是否稳定
- 编辑框（wxSTC）：部分性能优化，避免全量重建等
- 重新加载外部更改：修复关闭时仍然弹出提示更改对话框的问题
- 标记：修复菜单的状态错误

### 字体

主要涉及样式编辑器、编辑栏的字体选择。

- 样式编辑器 / 字体选择：修复用键盘选择时无法选择正确选项的问题
- 样式编辑器 / 字体选择：修复下拉框自动弹出时一些鼠标指针展示的问题，但受限于 windows api 只能在下拉框关闭后显示
- 样式编辑器 / 字体选择：修复下拉框自动弹出时重复打开的问题
- 字体选择：修复使用时显示前一个 tag block 中字体的问题
- 字体选择：开启「优先本地化」时也使用自绘窗体，不使用 Windows 原生对话框

### 查找 / 替换

- 结果对话框重命名列 Line 为 Line number，避免中文翻译错误

### 副字幕

- 副字幕：提升 srt 字幕样式使用和渲染的稳定性

### 可视化排版

- 测量参考线：样式优化，缩小端点避免使用时的遮挡，同步缩小箭头和减少线宽度
- 优化一些性能问题

### 插件（实验性）

- 开启 bridge 功能，可以调用更多的 api 并以 plugin 形式提供，目前只支持 dotnet 的 CoreCLR JIT 和 NativeAOT，但后者以 cabi 接入，理论上可以支持任何支持 cabi 交互的语言

### 构建 / 打包 / 运行时

- Windows 版本字符串生成脚本提升对 PowerShell 5.1 的兼容性
- plugin：新增 dependency-control v0.1.0（NativeAOT）
