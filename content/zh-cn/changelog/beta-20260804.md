**Beta 通道** GHA 快照（无 GitHub Release）。r9903，相对 [beta-20260801](/zh-cn/changelog/beta-20260801/) 的变更。

请从 [Actions](https://github.com/AmusementClub/Aegisub/actions/runs/30934967206) 下载 `aegisub-win-x64-portable.zip`。

### 编辑与界面

- 双击 override 标签可选中整个 `\tag(args)`

### 字体

主要涉及样式编辑器、编辑栏的字体选择。

- 字体选择中的预览根据行样式和光标所在 tag block 正确渲染
- 可选「输入时自动展开字体列表」，使用方向键和Enter来选择字体，默认关闭

### 查找 / 替换

- 结果对话框：增加「已替换行」列
- 结果对话框：修复在弹出的时候编辑使结果无法再次双击的问题，现在结果中被编辑的行同步变化而且置灰
- 结果对话框：修复无法 Esc 退出，而且退出后不是重新聚焦到 find / replace 框体的问题
- 结果对话框：高亮原始行和替换行中的关键字

### 自动化

- 新增 `aegisub.scroll_audio_to(time_ms)`，可以让 audio display 跳转到指定时间居中的位置

### 打包 / 运行时

- 构建版本号新增 `BUILD_GIT_BUILD_TIME` / `BUILD_GIT_BUILD_TIME_UTC`（时区由 `BUILD_TIME_OFFSET` 控制，默认 +8）
