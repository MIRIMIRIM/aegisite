[wangqr/Aegisub](https://github.com/wangqr/Aegisub/releases/tag/v3.3.2) 在 3.3.1 之后的错误修复版（无新功能）。

### v3.3.1 之后的更新

- 检测 32bit 内存上限并提示，以防止崩溃
- 解决了部分显卡驱动默认色深有误导致的花屏
- 使用 XAudio2redist 以更好支持 Windows 7
- 解决了多个 3.3.1 在 macOS 上崩溃的问题
- 解决吸色笔失效的问题
- 解决音频窗口中alt+鼠标拖动的问题
- 解决导出浮点数音频片段的问题
- 解决 Windows 上程序退出但临时文件未删除的问题
