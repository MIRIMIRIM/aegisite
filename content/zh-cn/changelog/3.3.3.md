[wangqr/Aegisub](https://github.com/wangqr/Aegisub/releases/tag/v3.3.3) 发布，基于 **[r8942](/zh-cn/changelog/r8942/)**。该 fork 最后一次带标签发布；之后进入本站维护的 AmusementClub 谱系（含 beta）。

英文原文：[3.3.3](/changelog/3-3-3/)。

### v3.3.2 之后的更新

- 向 libass 传递 storage size 以修复渲染（@TheOneric）
  - 使用 libass 时部分场景渲染结果变化，行为对齐 ffmpeg ≥ 5.0.1 与 VLC nightly
- macOS 增加 CoreAudio 播放器（多声道）（@IbarakiKasen）
- 字幕编辑框可在 wxStyledTextCtrl 与 wxTextCtrl 间选择
  - wxSTC：语法高亮
  - wxTextCtrl：系统原生控件（IME / 双向文字等往往更好）；Shift+右键为原生菜单
- 支持负边距（@petzku）
- 修复从 MKS 加载字幕时的时间戳问题
- 修复 ASS 内嵌字体支持（@Kienyew）
- 修复 boost ≥ 1.76、M1 Mac 等构建问题
